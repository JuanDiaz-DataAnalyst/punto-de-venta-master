# Componentes de terceros

Este proyecto usa los siguientes componentes gratuitos y de código abierto. Cada uno conserva su licencia.

| Componente | Uso | Licencia |
|---|---|---|
| [SQLite](https://sqlite.org) | Base de datos embebida | Dominio público |
| [Python](https://python.org) | Lenguaje / runtime | PSF License |
| [FastAPI](https://github.com/fastapi/fastapi) | API REST | MIT |
| [Starlette](https://github.com/encode/starlette) | Base de FastAPI | BSD-3-Clause |
| [Pydantic](https://github.com/pydantic/pydantic) | Validación de datos | MIT |
| [Uvicorn](https://github.com/encode/uvicorn) | Servidor ASGI | BSD-3-Clause |
| [pywebview](https://github.com/r0x0r/pywebview) | Ventana de escritorio | BSD-3-Clause |
| [openpyxl](https://foss.heptapod.net/openpyxl/openpyxl) | Exportación a Excel | MIT |
| [Chart.js](https://github.com/chartjs/Chart.js) v4.5.1 | Gráficas (incluido en `app/static/vendor/`) | MIT |
| [PyInstaller](https://github.com/pyinstaller/pyinstaller) | Generación del ejecutable | GPL-2.0 con excepción de bootloader |
| [Inno Setup](https://jrsoftware.org/isinfo.php) | Generación del instalador | Licencia Inno Setup (gratuita) |

El aviso de copyright y la licencia MIT de Chart.js se conservan en el encabezado de
`app/static/vendor/chart.umd.min.js`.
