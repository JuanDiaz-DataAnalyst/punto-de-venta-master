# Checklist de entrega — Punto de Venta MASTER

**Cliente:** ______________________  **Fecha:** ____ / ____ / ______  **Versión instalada:** ________  **Instaló:** ______________

## Antes de instalar
- [ ] Ejecuté `Verificar-equipo.bat` y resolví los avisos (Windows 64 bits, WebView2, impresora)
- [ ] Tengo el instalador `.exe` de la versión que voy a entregar
- [ ] Tengo el menú con precios, insumos con costos, gastos fijos mensuales y lista de usuarios del cliente

## Instalación
- [ ] Instalé el sistema y abre correctamente (ventana propia o modo navegador)
- [ ] Creé el administrador del negocio (**sin** datos de ejemplo) y anoté la contraseña en un lugar seguro
- [ ] Capturé categorías, insumos y productos con receta
- [ ] Capturé los gastos fijos (nómina, renta, luz, agua, gas…)
- [ ] Creé un usuario por cajero (tipo *User — Cajero*)
- [ ] Configuré el ticket (dirección, teléfono, mensaje, ancho 58/80 mm, IVA)
- [ ] La impresora está como predeterminada y el ticket sale completo y sin márgenes de más

## Prueba
- [ ] Abrí caja, abrí dos mesas, agregué productos, imprimí pre-cuenta, dividí una cuenta y cobré ambas
- [ ] El ticket impreso muestra folio y mesa
- [ ] Cancelé la venta de prueba y el inventario regresó
- [ ] Hice el corte de caja de prueba
- [ ] Exporté un reporte a Excel
- [ ] Probé cerrar y volver a abrir el sistema (las mesas abiertas siguen ahí)

## Entrega al cliente
- [ ] Mostré la operación diaria: abrir caja → mesas → cobrar → corte
- [ ] Mostré la tecla **F1** (Ayuda) y entregué la Guía del usuario
- [ ] Expliqué dónde están los datos y los respaldos, y que debe copiarlos a USB/nube cada semana
- [ ] Expliqué que cada computadora tiene su propia base de datos (no se comparte entre cajas)
- [ ] Anoté los datos de contacto de soporte con el cliente
